# Course Learning Outcomes (CLOs)
- The concept, background and importance of the term “software engineering,”
- Well‐ known software development process models, their key practices, and their salient features
- How to pick most suitable process models for the various types of projects
- To estimate cost and effort of a software product
- Requirements engineering process (elicitation, elaboration, modeling and specification of requirements)
- To construct architectural, component and UI design of a software product
- About various coding practices
- To test a software application using various techniques like Black box testing (equivalence class partitioning and boundary value analysis) and white box testing (Basis path testing)
- To deliver and deploy the constructed software program
