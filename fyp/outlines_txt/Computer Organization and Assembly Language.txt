# Course Learning Outcomes (CLOs)

- Understand basic concepts of computer organization with emphasis on lower-level abstraction of a computer system, including machine-level data representation, instruction set architecture, addressing modes, memory models, and assembly language programming.
- Understand interfacing and communication with hardware, including I/O fundamentals, interrupts and their structures, buses, external storage, and physical organization.
- Illustrate computer organization concepts using assembly language programming.
- Gain an introduction to Intel IA-32 architecture.
- Become familiar with assembly language directives, macros, operators, and program structures.
- Understand the interrelationship between hardware and software.
- Compare different processor families.
- Gain an introduction to computer architecture and pipelining.
