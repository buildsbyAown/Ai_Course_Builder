# Course Learning Outcomes (CLOs)
- List different steps of a Software Quality Assurance Program.
- Differentiate between black box and white box testing.
- Design test cases for black box and white box testing.
- Select appropriate number of test cases using an appropriate strategy.
- Execute test cases using software testing tools.
- Understand Software Testing Process
