# Course Learning Outcomes (CLOs)
- Understand and appreciate the pillars and advantages of the OO paradigm.
- Conduct a grammatical parse of a problem statement to identify the relevant abstractions (classes) and their attributes, operations, and relationships.
- Analyze a given problem and model it using UML diagrams
- Model the static aspects of a solution using a detailed UML design class diagram.
- Model the dynamic aspects of a solution using different UML state and interaction diagrams.
- Produce elegant and flexible designs using the concept of design patterns.
- Implement a given object-oriented design.
- Understand and apply the fundamental design principles.
